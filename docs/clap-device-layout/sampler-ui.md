# CLAP sampler UI extension v2

The optional plugin extension `org.klang-studio.komponist.sampler-ui/2` supplies snapshots and audition commands for a host-owned sampler front panel. The ABI is in [clap-sampler-ui.h](clap-sampler-ui.h). Plugin and host call it only on the CLAP main thread, after initialization and before destruction. The table is immutable and valid until destruction. Ordinary snapshot polling and preview callbacks may run while the audio processor is active. The plugin must keep its RT path independent of snapshot serialization and preview requests. It must neither wait for the main thread on the audio path nor retain the host's output buffer. The bundled samplers read loader metadata on the main thread and publish playhead and preview signals through atomics.

Version 2 adds an export tempo argument to the snapshot callback. Query the exact versioned extension ID before using its table. The earlier `/1` callback has a different signature.

`snapshot` receives a writable destination, its capacity and `export_tempo` in BPM. Pass `0.0` for ordinary polling. A positive finite value requests tempo preparation from samplers that support it. Only send such a request while no audio processing is running. Other values leave the requested tempo unchanged.

The host allocates up to 32 KiB and the callback returns the length of the complete payload. It returns zero if it cannot provide a complete snapshot. A snapshot contains at most eight pads and 512 overview peaks per pad. Peaks are unsigned amplitudes in `[0, 1]`. Zooming uses these fixed overview buckets. Editing positions and transients retain source-time precision. Playheads are fractions of source sample length in `[0, 1]`. Durations and transient positions use source seconds. Transients are capped at 256, and pad names and error messages are capped at 256 UTF-8 bytes. Hosts may display a loading state until the first snapshot arrives. The plugin sets `idle` after the loader has prepared its content for playback, including any requested tempo stretch.

The payload uses postcard. The [author SDK](../../sdk/native-clap/README.md) exports `sampler_ui::Snapshot` and its bounded `encode` method. They define the wire representation, including field and variant order. A host running a bridge requests snapshots on the control channel and uses the same bounds and schema. The host may request one snapshot per 80 ms. The command to start or release a slice preview uses source seconds and is ephemeral.

Sample assets, playback parameters and slice settings remain in CLAP state. The app owns project-relative links and resolves them before restoring the state in the plugin. The plugin owns decoding, playback and stretch buffers. Front panels must not treat a plugin's extension claim or project metadata as proof of trusted origin. Komponist uses its built-in Sampler and General Sampler editors only for its authenticated packaged instances. An ordinary CLAP host can ignore this extension and play the instruments with the standard CLAP interface.

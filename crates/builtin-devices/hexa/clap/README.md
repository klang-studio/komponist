# Hexa CLAP bundle

Stable plugin ID `org.klang-studio.komponist.hexa`. The parameter inventory includes
all wire slots and macro keys.

The versioned CLAP state field retains the entire Hexa patch, including
filters, routing, modulation and effects that are outside the visible
parameter bindings.

The native layout publishes the interactive FM routing diagram and operator selector.
It binds the controls to the authoritative author-to-CLAP IDs. The Presets browser
and device menu load factory patches as ordinary CLAP state.
